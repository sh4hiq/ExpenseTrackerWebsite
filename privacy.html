Last updated: October 18, 2026

Scope: ExpenseTracker is a personal application that runs locally on its owner's computer. It is not a public service for other users.

1. Information accessed

When the owner authorizes access, ExpenseTracker uses Google OAuth and the Gmail API with the read-only scope gmail.readonly. It lists only messages that match the configured bank sender (by default comunicazioni@isybank.com) within the sync window. For those messages it reads the sender, subject, date header and message body. It cannot send, modify or delete email.

2. How information is used

Email data is used only for the owner's personal expense tracking: identifying payment notifications and extracting the amount, currency, merchant, date and transaction type. Email data is not sold, used for advertising, or used to train AI models.

3. Local processing

All processing happens on the owner's computer. Text extraction and category suggestions use a language model served locally by LM Studio on 127.0.0.1. Bank email text is never sent to hosted AI services, analytics or telemetry. The only external network traffic is to Google, for authentication and Gmail API requests.

If the owner configures additional integrations or remote services, data may also be sent to them, and this policy must be updated to describe it.

4. Storage and security

Transactions and cleaned email text are stored in a local SQLite database. Messages that are not expenses keep only metadata, with no body text. OAuth credentials and tokens are stored in a local secrets folder and are never printed or logged. Logs are redacted and do not contain email bodies.

The owner is responsible for protecting the computer and keeping the database, backups, exports and token files secure. Credentials, tokens and email data must never be committed to a source code repository.

5. Data retention and deletion

Data stays on the owner's computer until the owner deletes it. The owner can delete the local database, backups and token at any time and can revoke the application's Google access. Revoking access does not automatically delete data already stored locally.

6. Google account permissions

Access can be reviewed or revoked at any time from Google Account permissions. After revoking, the application cannot access Gmail until it is authorized again.

7. Sharing and third parties

ExpenseTracker does not disclose Gmail data to anyone. Google services are used for authentication and Gmail API access and are subject to Google's own terms and privacy practices.

8. Limited Use

ExpenseTracker's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

9. Changes to this policy

This policy is updated whenever the application's functionality or data handling changes. The date at the top shows the latest revision.

10. Contact

For questions about this application or this policy, contact the application owner at the support email address shown on the Google consent screen.
